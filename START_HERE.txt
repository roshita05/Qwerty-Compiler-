QWERTY Compiler - Start Here
============================

1. Extract the complete ZIP. Do not run files from inside the ZIP viewer.
2. Open the qwerty-compiler folder containing README.md and START_QWERTY.bat.
3. You need Python 3.11 or newer. No additional packages are required.
4. On Windows, double-click START_QWERTY.bat and leave its terminal open.
5. Open http://127.0.0.1:8765 in your browser.
6. Click Run code to execute the welcome example.

Terminal alternative, from this folder:
    py -3 -m qwerty web

Use python or python3 instead of py -3 on installations that use those commands.
Read README.md for examples, command-line compilation, and troubleshooting.
Read BUILTINS.md for the full 80-function reference.

This is a LOCAL development application, not a public code-execution sandbox.
